# Full Adder using Verilog HDL

A simple implementation of a **1-Bit Full Adder** using Verilog HDL along with a testbench for simulation and verification.

---

## 📌 Project Overview

A Full Adder is a combinational logic circuit that adds three single-bit binary inputs:

* Input A
* Input B
* Carry Input (Cin)

It produces:

* Sum Output (Sum)
* Carry Output (Carry)

This project demonstrates the design and simulation of a Full Adder using Verilog HDL.
